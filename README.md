# OR Practice

Exercises in optimization, routing, stochastic models and econometrics, to keep the skills from my MSc Econometrics and Operations Research (Erasmus University Rotterdam) sharp.

## Topics
- Integer programming and facility location
- Routing (TSP, CVRP, VRPTW)
- Decomposition (column generation, Benders, Lagrangian relaxation)
- Heuristics and metaheuristics
- Stochastic and dynamic problems, queueing
- Econometrics and statistics

## Tools
Java, CPLEX, Python, R

## Structure
Each exercise has its own folder with a README that explains the problem, the formulation, how to run the code and the results.

## Note on CPLEX
The CPLEX library and license are not included. To run the Java code, you need your own CPLEX installation
